# AI usage disclosure

Generative AI assistance was used during development for code drafting and refactoring, test and QA suggestions, documentation editing and cartographic iteration.

The project author retained responsibility for the analytical decisions, reviewed the supplied and downloaded spatial data, manually checked the site origins and identified network connections, selected the final C1 presentation method, supplied API credentials locally and reviewed the resulting maps. Analytical results are generated by the versioned Python scripts and are not copied from model responses.

AI suggestions were treated as provisional until checked against source data, saved QA outputs, tests or rendered figures. API keys and other credentials are excluded from the repository.
